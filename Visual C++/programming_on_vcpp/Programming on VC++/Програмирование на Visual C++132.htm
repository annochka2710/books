Модификация ресурсов

  • Откройте меню вашей новой программы, удалите все пункты меню, кроме Edit и Help.
  • В меню Edit удалите все пункты и оставьте только Exit. Затем добавьте пункт &Clear, задайте ему идентификатор как ID_EDIT_CLEAR. Перейдите в ClassWizard добавьте функцию-обработчик сообщения WM_CHAR. Добавьте обработчик сообщения COMMAND идентификатора ID_EDIT_CLEAR. Добавьте для них функции и названия примите по умолчанию.

    Добавление кода

  • Добавьте в класс CEchoDoc переменную m_TextLine типа CString. Она будет хранить текст строки.
  • Добавьте следующий код в функцию обработки сообщения WM_CHAR: 
    

void CEchoView::OnChar(UINT nChar,
		 UINT nRepCnt, UINT nFlags) 
{
	
	//Получить указатель на документ
	CEchoDoc* PDoc=GetDocument();
	
	/*Если нажата служебная клавиша,
	 то вывести звуковой сигнал.*/
	if(nChar<32)
	{
		::MessageBeep((UINT)-1);
		return;
	}
		
	//Добавить введеный символ
	PDoc->m_TextLine+=nChar;

	CClientDC ClientDC(this);
	
	//Установить цвет и фон шрифта
	ClientDC.SetTextColor(::GetSysColor(COLOR_WINDOWTEXT));
	ClientDC.SetBkMode(TRANSPARENT);
	
	//Вывести текст
	ClientDC.TextOut(1,1,PDoc->m_TextLine);
	

	CView::OnChar(nChar, nRepCnt, nFlags);
}
  • Думаю все должно быть понятно, только с комментариями. Скажу одно, что код служебных клавиш, типа Ctrl, Alt, F1 и.т.д. всегда меньше 32.
  • Функция SetBkMode(TRANSPARENT) либо разрешает, либо запрещает окраски фона, в данном случая разрешает. Значит фон текста будет белое окно представления.
  • Теперь нужно добавить код в функцию OnDraw, так как при любом "удобном" случае тест программы будет стираться: 
    
void CEchoView::OnDraw(CDC* pDC)
{
	// TODO: add draw code for native data here
	//Получить указатель на документ
	CEchoDoc* pDoc = GetDocument();
	ASSERT_VALID(pDoc);
	
	//Вывести текст системным цветом
	pDC->SetTextColor(::GetSysColor(COLOR_WINDOWTEXT));
	pDC->SetBkMode(TRANSPARENT);
	pDC->TextOut(1,1, pDoc->m_TextLine);
}
  • Без комментариев.
  • Добавим код очистки окна в функцию OnEditClear(): 
    
void CEchoView::OnEditClear() 
{
	// TODO: Add your command handler code here
	CEchoDoc* pDoc=GetDocument();

	//Очистить строку
	pDoc->m_TextLine.Empty();

	//Уничтожить окно представления
	pDoc->UpdateAllViews(NULL);
}
  • Вначале вы получаете указатель на документ, потом очищаете строку методом Empty() и разрушаете окно представления.
