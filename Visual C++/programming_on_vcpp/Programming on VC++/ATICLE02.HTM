Изменение стандартного курсора

  • Сейчас вы научитесь как можно изменить стандартный курсор-стрелку на другие более подходящие для работы, также получите полный список таких курсоров.
  • Для начала списочек:
    IDC_ARROW - Стандартный курсор-стрелка.
    IDC_CROSS - Крестовина из тонких линий.
    IDC_IBEAM - I лучевой курсор, используемый для перетягивания файла.
    IDC_ICON - Прямоугольный курсор, используемый для перетягивания файла.
    IDC_ SIZE - Квадратный курсор с меньшим квадратом внутри, используемый для задания размера объекта.
    IDC_SIZENESW - Двунаправленый курсор-стрелка с концами, указывающими на северо-восток и юго-запад.
    IDC_SIZENS - Двунаправленый курсор-стрелка с концами, указывающими на север и юг.
    IDC_SIZENESW - Двунаправленый курсор-стрелка с концами, указывающими на северо-запад и юго-восток.
    IDC_SIZENESW - Двунаправленый курсор-стрелка с концами, указывающими на запад и восток.
    IDC_UPARROW - Курсор вертикальная стрелка.
    IDC_WAIT - Курсор песочные часы, используемый при выполнении длительной задачи.
  • Для того, чтобы изменить курсор надо вначале загрузить его в память, и передать его параметры cтруктуре HCURSOR.
  • Добавляете в проект переменную HCURSOR m_HCursor
  • Загружаете ее в конструкторе вашего класса представления или диалогового окна:
    AfxGetApp->LoadStandartCursor(IDC_CURSOR) -здесь может быть любой из представленных выше курсоров.
  • Там где вы хотите заменить курсор пишите ::SetCursor(m_HCursor). Можно сделать это в функции OnMouseMove при рисовании например.

  • В догонку к мыши хочу сказать, что командой ::ClipCursor(&Rect) и ::ClipCursor(NULL) вы можете удерживать курсор в области Rect и отпускать той же командой только с параметром NULL.
