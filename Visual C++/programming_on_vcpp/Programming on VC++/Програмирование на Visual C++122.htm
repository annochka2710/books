Создание начальной страницы

Сейчас мы создадим ресурс HTML страницы, которая будет появляться каждый раз при запуске программы.
  • Добавьте в ресурсы ресурс HTML, переменуйте его в IDR_HOME. Вставьте следующий код в этот ресурс:
    <HTML>
    <HEAD>
    <META NAME="GENERATOR" Content="Microsoft Developer Studio">
    <META HTTP-EQUIV="Content-Type" content="text/html; charset=windows-1251">
    <TITLE>Document Title</TITLE>
    </HEAD>
    <BODY>
    <!-- Insert HTML here -->
    <CENTER>
    <H2>INTERNET LINKS</H2>
    <P>
    <A HREF="http://www.aks.com">Yhe American!</A>
    <P>
    <A HREF="http://www.uka.ru">UKA Ru</A>
    </CENTER>

    </BODY>
    </HTML>

    Теперь откройте функцию OnInitalUpdate() модифицируйте ее следующим образом: 

    
void CBView::OnInitialUpdate()
{
	CHtmlView::OnInitialUpdate();

	//--- Ваш код ---//
	LoadFromResource(IDR_HOME);
	//--- Ваш код ---//

}

    Использование навигации

  • Теперь мы добавим панель инструментов, с помощью которой, мы сможем перемещаться по ссылкам вперед и назад, останавливать загрузку страницы, вызывать поиск.
  • Откройте панель инструментов.Удалите кнопки New,Cut, Copy, Paste, оставив только Open, Save,Print и Help. Затем вызовите пункт меню File->Open. Найдите каталог: Visual Studio\Common\Graphics\Icons. В выпадающем списке типов файлов выбирете Image Files. Откройте подкаталог Arrows, выделите два файла Arw04lt.ico, Arw04rt.ico, в подкаталоге Computer - файл W95mbx01.ico(белый крестик в красном кругу). Откройтк Earth.ico из подкаталога Elements и Binoculr.ico из подкаталога Misc.

    Создание кнопок панели инструментов

  • Теперь скопируйте первое изображение стрелки влево в буфер, перейдите на панель инструментов и на пустом месте вставьте это изображение. Так же проделайте с остальными иконками. Настройте панель инструментов, используя следующую таблицу:

    Изображение Идентификатор Строка подсказки
    Arw04lt.ico ID_WEB_BACK Вернуться к предыдущей WEB-странице\nНазад
    Arw04rt.ico ID_WEB_FORWARD Перейти к следующей WEB-странице\nВперед
    W95mbx01.ico ID_WEB_STOP Остановить загрузку текущей страницы\nСтоп
    Earth.ico ID_WEB_OPEN Открыть WEB-сайт\nОткрыть сайт
    Binoculr.ico ID_WEB_SEARCH Искать в Web\n Поиск

    Создание пунктов меню

  • Добавьте в меню File пункт Open Web Site сразу после пункта Open, установив идентификатор ресурса в ID_WEB_OPEN.
  • Удалите меню Edit.
  • Добавьте новое меню Navigate и поместите в него пункты Back, Forward и Stop. Убедитесь, что для них используются те же идентификаторы ресурса, что и для кнопок панели инструментов.
  • В меню Help добавьте команду ID_WEB_SAERCH, сразу за пунктом About и установите ее заголовок как &Search the Web.
  • Откройте таблицу акселераторов, а затем при помощи возможности Use Next Key Typed добавьте новые акселераторные возможности для трех пунктов меню Navigate. Для кнопки Forward - нажмите Ctrl + стрелка вправо, для Back - , а для кнопки Stop - Esc.

    Обработка CBView

  • Давайте теперь подключим код для кнопок.
  • С помощью Class Wizard добавьте обработчик сообщения для идентификаторов ресурсов ID_WEB класса CBView.
  • В ClassWizard'e выбирете из списка Object IDs класс CBView, а из списка Messages - OnDocumentComplete. Щелкните Add Function для перекрытия этой виртуальной функции.
  • Добавьте код из листинга 1 в функции, сгенерированные ClassWizard. 
    
void CBView::OnWebBack() {GoBack();}
void CBView::OnWebForward() {GoForward();}
void CBView::OnWebSearch() { GoSearch();}
void CBView::OnWebStop() {Stop();}
void CBView::OnDocumentComplete(LPCTSTR lpszURL) 
{
	CHtmlView::OnDocumentComplete(lpszURL);
	//Установка заголовка главного окна
	AfxGetMainWnd()->SetWindowText(GetLocationName());
}
  • Каждая функция CBView обращается к функции класса CHtmlView, вот и весь фокус.
