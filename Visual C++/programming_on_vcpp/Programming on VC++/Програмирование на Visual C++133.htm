Урок XIII

Управление кареткой

  • Вначале добавьте обработчики сообщений и функции к ним: WM_CREATE, WM_KILLFOCUS, WM_SETFOCUS. Названия функций примите по умолчанию.
  • В класс CEchoView добавьте три переменные описывающие размеры каретки и расстояние ее от левого угла окна программы: POINT m_CaretPos и int m_Xcaret? m_Ycaret.
  • В конструктор класса CEchoView добавьте следующую инициализацию:
    m_CaretPos.x=m_CaretPos.y=1;. Это начальная позиция каретки.
  • Добавьте следующий код в функцию OnCreate класса CEchoView: 
    
int CEchoView::OnCreate(LPCREATESTRUCT lpCreateStruct) 
{
	if (CView::OnCreate(lpCreateStruct) == -1)
		return -1;
	
	// Ваш код начинается здесь-//

	CClientDC ClientDC(this);
	
	//Создать объект структуры параметров шрифта
	TEXTMETRIC TM;

	//Получить параметры шрифта
	ClientDC.GetTextMetrics(&TM);

	//Установить толщину каретки
	m_Ycaret=::GetSystemMetrics(SM_CXBORDER)*2;

	//Установить высоту каретки
	m_Xcaret=TM.tmHeight+TM.tmExternalLeading;

	//- Ваш код заканчивается здесь -//

	return 0;
}
  • Вначале вы создаете объект структуры, которая будет хранить параметры шрифта.
  • Вы считывает параметры, устанавливате ширину каретки, затем высоту. Подробнее о параметрах шрифта вы узнаете в следующем уроке.
  • Теперь добавим код в функцию OnSetFocus, эта функция запускается всякий раз, когда окно программы создается или получает управление: 
    
void CEchoView::OnSetFocus(CWnd* pOldWnd) 
{
	CView::OnSetFocus(pOldWnd);

	//  - Ваш код - //
	
	//Создать каретку, выбранных размеров
	CreateSolidCaret(m_Ycaret,m_Xcaret);
	
	//Установить позицию каретки
	SetCaretPos(m_CaretPos);

	//Показать каретку
	ShowCaret();
}
  • Теперь добавим код разрушения каретки в функцию OnKillFocus, она запускается каждый раз, когда окно программы теряет управление(вы перешли, например, в другую программу). Почему надо удалять каретку каждый раз, а потому что она одна на всю Россию, и нужна для других программ.
  • Вставьте в функцию OnKillFocus следующую строчку:
    ::DestroyCaret();.
  • Теперь модифицируем функцию OnChar, так что при вводе символа каретка передвигалась и при нажатии кнопки Backspace символ удалялся: 
    
void CEchoView::OnChar(UINT nChar, UINT nRepCnt,
	 UINT nFlags) 
{
	////- Ваш код начинается здесь -////
	
	//Получить указатель на документ
	CEchoDoc* PDoc=GetDocument();

	/*Если была нажата служебная клавиша и не BackSpace,
	то вернуться*/
	if(nChar<32&&nChar!=8)
	{
		::MessageBeep((UINT)-1);
		return;
	}
	//Настроить цвет текста
	CClientDC ClientDC(this);
	ClientDC.SetTextColor(::GetSysColor(COLOR_WINDOWTEXT));
	ClientDC.SetBkMode(TRANSPARENT);

	//Если было нажата BackSpace
	if(nChar==8)
	{
		//Получить длину строки
		if(PDoc->m_TextLine.GetLength()==0)return;
		
		//Удалить один символ справа
		PDoc->m_TextLine.Delete(
			PDoc->m_TextLine.GetLength()-1,1);
	
		//Уничтожить окно представления
		PDoc->UpdateAllViews(NULL);
	}
	
	/*Если нажат BackSpace,то его не добавлять к строке*/
	if(nChar!=8)PDoc->m_TextLine+=nChar;
	
	//Получить геометрические размеры строки
	CSize Size=ClientDC.GetTextExtent(PDoc->m_TextLine,
				PDoc->m_TextLine.GetLength());

	//Спрятать каретку
	HideCaret()

	//Вывести текст;
	ClientDC.TextOut(1,1,PDoc->m_TextLine);

	//Получить позицию по X каретки
	m_CaretPos.x=Size.cx;
	
	//Установить позицию каретки
	SetCaretPos(m_CaretPos);

	//Показать каретку
	ShowCaret();

	//// - Ваш код заканчивается здесь -////	

	CView::OnChar(nChar, nRepCnt, nFlags);
}
  • Здесь поясню только, то что функция HideCaret() скрывает каретку, т.к. потом выводится текст и он может наложиться на нее, фнукция GetTextExtent() передает размеры строки в пикселах, эта длина будет использоваться для установки каретки в новую позицию после строки.
  • Остальное должно быть понятно из комментариев, не будем повторяться.
  • Добавьте следующие две строчки в конец функции OnEditClear(), они будут устанавливать позиции каретки на нулевую позицию: 
    
m_CaretPos.x=1;
SetCaretPos(m_CaretPos);
  • Добавьте обычное обращение к функции CWnd::SetWindowText,для установки заголовка окна, в функцию InitInstance класса CEchoApp:
    m_pMainWnd->SetWindowText("Echo");.
